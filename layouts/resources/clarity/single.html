02 / THE IDEA

Good editing starts before the edit.

Clarity’s central question is simple: what does this reader need from this piece? The skill uses that answer to guide the argument, the language and the final read-through.

That makes it useful when a draft sounds polished but still says little, when an edit has flattened the author’s voice, or when the agent needs to ask for missing evidence instead of inventing it.

03 / THE FRAMEWORK

18 rules, grouped around the work.

A compact map of the method—not a substitute for the original rules and examples.

01—05 5 RULES

Useful

Choose a reader, understand what they bring, decide what they should take away, add what only the author can contribute, and cut repetition.

06—10 5 RULES

Clear

Make claims concrete, give sentences an actor, prefer plain words, trim excess, and state the relationship between ideas.

11—13 3 RULES

Yours

Take a position, write in a voice you would use with a colleague, and avoid performing expertise or humility.

14—18 5 RULES

Making it

Earn the next sentence, connect paragraphs, stop when the thought ends, rewrite by cutting and reordering, then read aloud.

Summarised from Clarity by Addy Osmani. Explore the original rules ↗

04 / THREE MODES

Pick the kind of help the draft needs.

The skill has three distinct entry points. Each keeps the author in control of what is written and changed.

01

Interview

Start with a topic. Clarity asks for the author’s experience and language, then co-writes from those answers.

/clarity interview
02

Rewrite

Give it an existing draft. It edits the prose while keeping the facts and intent that belong to the source.

/clarity rewrite
03

Review

Ask for a critique. Clarity identifies what needs attention and leaves the file unchanged.

/clarity review

Clarity works with Claude Code, Codex and other agents that can load Agent Skills. In Codex, the project also documents natural-language mode requests.
